# IAstro

This repository contains work from my two internships at the **Institute of Astrophysics and Space Sciences** (Portugal) through the **IAstro Summer Internship program** in 2023 and 2025.

I have recently revisited the projects, added comments, and cleaned up parts of the code before archiving them here. The original work was carried out during the internships; these later edits are intended to make it easier to read and explore.
