# Galactic Archaeology Internship Notebooks

Two notebooks from my IAstro Summer Internship 2025 exploring a synthetic Milky Way–like galaxy (m12f). The broader goal was to use simulated galaxies to develop data-analysis and machine-learning approaches and show that they can be utilised for reconstructing galactic history: **galactic archaeology**.

| Notebook | What it covers |
| --- | --- |
| `IAstro Summer Internship 2025_Maryam.ipynb` | Guided practice with FIRE-2 simulation data: stellar positions, motions, ages, and chemical abundances. The exercises and original notebook framework were created by my supervisor, Andreas W. Neitzel; the solutions and interpretation notes are mine. |
| `IAstro2025_Project 4_Maryam.ipynb` | My project analysis of synthetic stellar observations: characterizing disk and halo populations, training classifiers, and using unsupervised learning to investigate halo substructure and the galaxy's history. The approach was developed through discussions with my teammates. |

**Data availability:** The large simulation snapshot and the internship-supplied CSV are not included here. The notebooks retain their saved figures and outputs for reading, but rerunning them requires the corresponding input data and Python packages imported in each notebook.
